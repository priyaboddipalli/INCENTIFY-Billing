# Electron → Web mapping

- `data-load` → authenticated `bootstrap` API
- `data-save` → record-level patch + server revision/LockService
- invoice number → server reservation
- PDF → isolated browser print / Save as PDF
- Excel → server-generated XLSX download
- Razorpay → server-side Apps Script gateway using Script Properties
- external links / clipboard → browser APIs
- Electron window buttons → hidden/no-op
- local JSON → private Drive state + Sheets mirrors
